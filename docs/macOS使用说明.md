# 轻墨 QingMo — macOS 版说明

按你的 Mac 芯片选择安装包，优先使用 DMG 拖拽安装；ZIP 可解压使用。

---

## 选哪个文件

| 你的 Mac | 安装包 | 免安装包 |
| --- | --- | --- |
| Apple 芯片（M 系列） | `轻墨-<版本>-mac-arm64.dmg` | `轻墨-<版本>-mac-arm64.zip` |
| Intel 芯片 | `轻墨-<版本>-mac-x64.dmg` | `轻墨-<版本>-mac-x64.zip` |

GitHub 下载文件以 `QingMo-` 开头，本地交付目录使用「轻墨」前缀；请选择与芯片一致的架构。

**怎么知道自己是什么芯片**：左上角  → 关于本机 → 看「芯片」那一行。  
显示「Apple M1/M2/M3/M4」就用 arm64，显示「Intel」就用 x64。

2020 年后买的 Mac 基本都是 Apple 芯片。

---

## 安装步骤

1. 双击 DMG，或解压 ZIP，得到「轻墨.app」
2. 把「轻墨.app」拖进「应用程序」文件夹（替换旧版前先保存文档并退出轻墨）
3. 首次打开如遇系统确认，在访达中右键点击应用并选择「打开」

完成。访达里显示的名字&#x662F;**「轻墨」**，右键打开后以后就能正常双击了。

---

## 为什么必须右键打开？

因为应用**没有 Apple 签名和公证**。

macOS 的 Gatekeeper 会对未签名应用直接拦截，双击只会弹「已损坏，无法打开」，  
这是误报——应用本身没问题。

绕过方式就是**右键 → 打开**，这是 Apple 官方留的口子。

### 右键也不行的话

打开「终端」（聚焦搜索 Terminal），粘贴执行：

```bash
xattr -dr com.apple.quarantine /Applications/QingMo.app
```

然后再双击。

---

## 能免掉这个提示吗？

能，但需要：

- Apple 付费开发者账号（$99/年）
- 在 Mac 上用 `codesign` 做代码签名
- 提交 Apple 公证（notarization）

个人项目一般不建议为一次性的发布付这个钱。如果要发布正式版本，  
在 Mac 上跑 `npm run pack:mac` 出 `.dmg`，再配签名即可。

---

## 这是 zip 不是 dmg

`.dmg` 需要 macOS 系统的 `hdiutil` 工具生成，**在 Windows 上做不出来**。

本目录的 `.app` 已经打包好了，Windows 上交叉生成，省得你装个虚拟机。  
解压出来和正常 `.app` 完全一样，只是少了 dmg 那个「拖到应用程序」的安装壳。

如果你以后有 Mac 机器，想出正式 dmg：

```bash
npm run pack:mac
```

## 常见问题

**Q：能打开 .md 文件吗？**  
能。「文件 → 打开」选 `.md`，或直接把文件拖到窗口上。

**Q：文件会上传吗？**  
不会。完全离线运行，无账号、无服务器、不收集任何数据。

**Q：怎么卸载？**  
把 `/Applications/QingMo.app` 拖到废纸篓即可。

**Q：怎么升级？**  
下载新版 `.app` 覆盖旧的，或者先删旧的再拖新的。

**Q：应用名和文件名不一致？**  
`QingMo.app` 是 macOS 的命名惯例（内部标识用英文），  
你在访达和应用菜单里看到的都是中文「轻墨」。

## 自动检查与下载更新

应用启动后会自动查询官方 GitHub Release，之后每 6 小时再次检查。有更高版本且提供本机安装包时，会在后台下载并显示进度。下载校验完成后会询问是否安装。

下载适合本机 Apple 芯片或 Intel 的 DMG。点击「打开安装包」后，请先保存文档并退出轻墨，再将 DMG 内的轻墨拖入 Applications 替换旧版。

选择「稍后」会保留已下载的安装包，可从更新提示或「设置 → 检查更新」再次打开。应用不会未经确认安装或强制退出。网络失败会在 15 分钟后重试，也可点击「重试下载」；没有本平台安装包或无法核对文件时，可打开发布页手动下载。

## 插入本地图片

使用「插入图片 → 本地图片」选择文件，支持带中文、空格和括号的文件名。已保存文档按文档目录引用图片，未保存文档保留绝对路径。移动文档时请一并保留相对路径对应的图片文件。导出 HTML 会内嵌本地图片，方便独立查看。

## 列表编辑与清除当前行格式

开启预览区直接编辑后，在列表项内按 Enter 会自动续写，空列表项再按 Enter 可退出。直接点击编辑区中的有序列表序号（预览区和源码区均支持），可选择从 1 重新编号，或从指定数字开始。点击清除格式图标，或按 `Ctrl/Cmd+\`，可清除当前行的标题、引用、列表和行内样式，不影响其他行。

## 未保存文档的关闭提示

关闭前可选择“保存并关闭”“放弃保存”“返回确认”。“返回确认”会回到编辑器；“放弃保存”还需再次点击“确认放弃保存”，未保存修改才会丢弃。取消保存或保存失败时，文档保持打开。全部关闭和退出应用使用相同流程。

## 文档大纲

点击工具栏“大纲”打开或隐藏右侧标题导航，右上角 × 可关闭；状态会记住。支持 H1–H6、Setext 标题，代码块内容不计入大纲。点击标题跳转，修改正文标题后自动更新。
