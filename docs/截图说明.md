# README 截图说明

截图使用轻墨真实渲染器，公开演示文档位于 `docs/examples/`。不会读取用户文件、应用会话或诊断日志，也不会修改安装在应用程序文件夹中的轻墨。

## 重新生成

在仓库根目录运行：

```bash
npm --prefix dev run build:renderer
env -u ELECTRON_RUN_AS_NODE dev/node_modules/.bin/electron dev/scripts/capture-readme.js --no-sandbox --disable-gpu
```

Windows 终端运行前清除 `ELECTRON_RUN_AS_NODE`，然后执行 `dev\node_modules\.bin\electron dev/scripts/capture-readme.js`。实际像素尺寸与主机显示比例、工作区高度有关。

README 中新功能以当前源码为准；下载版本以 GitHub Release 的实际发布内容为准。更新截图前先验证功能，再调整演示文案，避免让界面图与产品行为不一致。
