# 轻墨 QingMo — Windows 版说明

本目录有 **3 种形态**，用途不同，别下错了。

---

## 三种文件对比

| 名称 | 大小 | 双击会怎样 | 用它做什么 |
| --- | --- | --- | --- |
| `轻墨 Setup 1.3.0.exe` | 83 MB | 弹出安装向导 | **日常使用推荐**，装到电脑里 |
| `轻墨 1.3.0.exe` | 83 MB | 先解压到临时目录，再启动，**首次会等 5-10 秒** | 只想临时用一次，或放 U 盘 |
| `portable/轻墨.exe` | 189 MB | **立即启动**，没有解压过程 | 真正的"双击即用" |

### 关键区别

**`轻墨 1.3.0.exe`（单文件版）不是真正的单文件程序。**

它是个 NSIS 自解压安装器，双击后会把 293MB 的完整应用解压到
`%TEMP%` 再启动。所以：

- 首次启动**明显慢**（5-10 秒），要等它解压
- 杀毒软件可能报警（自解压行为容易误判）
- 每次运行都要重新解压

**如果你想要「点了就开、秒启动」，用 `portable/` 目录里的那个。**

用法：把整个 `portable/` 文件夹复制到任意位置（U 盘也行），
双击里面的 `轻墨.exe`。整个文件夹是完整的，**不能只拷 exe**。

## 该选哪个

| 你的情况 | 选|
| --- | --- |
| 每天用，固定装在电脑上 | `轻墨 Setup 1.3.0.exe` |
| 临时打开一次某个 .md | `轻墨 1.3.0.exe` |
| 放 U 盘随身带，追求秒开 | `portable/` 整个文件夹 |
| 公司的电脑，不允许安装 | `portable/` 整个文件夹 |

## 安装版会被拦吗？

可能会。Windows提示「未知发布者」，因为没买代码签名证书（一年几百美元，个人项目一般不做）。

**解决办法**：

1. 点「更多信息」
2. 点「仍要运行」

或者：右键 → 属性 → 底部勾选「解除锁定」→ 确定，之后就能正常双击。

---

## 文件放哪？

程序装哪都行，但**你编辑的 .md 文件自己保管**，软件不负责备份。

建议：

- 用「文件 → 打开」选文档，或直接把 .md 拖进窗口
- 用「文件 → 另存为」保存到你自己的目录（如 `文档\笔记\`）
- 状态栏显示「已保存」（绿色）才是真的存到磁盘了
- 显示「● 未保存」（橙色圆点）说明改动只在编辑区里，**这时候关窗口虽然有草稿暂存，但不保险**

轻墨不联网、不上传、不收集任何数据，文件只在你本机。

## 卸载

安装版：Windows 设置 → 应用 → 找到「轻墨」→ 卸载。

便携版（单文件或 portable 目录）：直接删掉即可，不留注册表。

## 自动检查与下载更新

应用启动后会自动查询官方 GitHub Release，之后每 6 小时再次检查。有更高版本且提供本机安装包时，会在后台下载并显示进度。下载校验完成后会询问是否安装。

下载本机架构对应的安装程序。点击「打开安装包」启动安装向导；请先保存文档，再按向导提示关闭轻墨并安装。便携版用户也可用该安装程序安装新版。

选择「稍后」会保留已下载的安装包，可从更新提示或「设置 → 检查更新」再次打开。应用不会未经确认安装或强制退出。网络失败会在 15 分钟后重试，也可点击「重试下载」；没有本平台安装包或无法核对文件时，可打开发布页手动下载。

## 插入本地图片

使用「插入图片 → 本地图片」选择文件，支持带中文、空格和括号的文件名。已保存文档按文档目录引用图片，未保存文档保留绝对路径。移动文档时请一并保留相对路径对应的图片文件。导出 HTML 会内嵌本地图片，方便独立查看。

## 列表编辑与清除当前行格式

开启预览区直接编辑后，在列表项内按 Enter 会自动续写，空列表项再按 Enter 可退出。直接点击编辑区中的有序列表序号（预览区和源码区均支持），可选择从 1 重新编号，或从指定数字开始。点击清除格式图标，或按 `Ctrl/Cmd+\`，可清除当前行的标题、引用、列表和行内样式，不影响其他行。

## 未保存文档的关闭提示

关闭前可选择“保存并关闭”“放弃保存”“返回确认”。“返回确认”会回到编辑器；“放弃保存”还需再次点击“确认放弃保存”，未保存修改才会丢弃。取消保存或保存失败时，文档保持打开。全部关闭和退出应用使用相同流程。

## 文档大纲

点击工具栏“大纲”打开或隐藏右侧标题导航，右上角 × 可关闭；状态会记住。支持 H1–H6、Setext 标题，代码块内容不计入大纲。点击标题跳转，修改正文标题后自动更新。
