# 商业化与渠道建议

以下是产品方案建议，尚未接入广告、支付、订阅或权益服务器。

## 推荐路径

先保留本地编辑、保存、大纲等基础能力，做好稳定性与口碑；之后增加自愿打赏，再验证专业版需求。二维码原图在 `docs/assets/support-qr.png`，已在 README 展示。未来应用内可在“关于 / 支持作者”中提供入口，默认不弹出、不遮挡写作。二维码打赏不自动等同购买授权。

## 广告

写作场景需要安静，优先考虑用户主动打开的“发现 / 资源”页或关于页赞助位，明确标注广告。不要在编辑内容中插广告，不修改导出的文档，不通过读取正文来定向投放。接入广告网络前，再明确其数据采集范围与退出方式。更适合先做少量固定赞助，而不是立即接入行为追踪 SDK。

## 可以验证的付费能力

- 一次性专业版：批量导出、排版模板、自定义样式、文档库检索和更完整的版本历史。先访谈用户并做试用，再定价格。
- 持续服务：跨设备同步、云备份和团队协作，按持续服务收费。需要真实的账号、存储、冲突处理、恢复与运维能力。
- AI 可选功能：自带 API Key，或购买明确额度；发送正文前让用户选择范围并知情。把模型调用成本与编辑器基础能力分开。

真正销售前需要订单、授权凭证、权益校验、退款处理与支持流程。不能只靠前端开关保护权益，也不能用一张个人打赏码承诺自动开通会员。定价、支付方案与适用地区规则应在正式方案确定时核实。

## 腾讯及其他分发渠道

轻墨是 Electron 桌面软件，目前提供 Windows EXE 与 macOS DMG / ZIP。腾讯软件中心（https://pc.qq.com/）面向 PC 软件；应用宝官网（https://sj.qq.com/）同时展示移动应用与电脑版产品，腾讯应用开放平台入口为 https://app.open.qq.com/ 。

因此应先向腾讯确认“Windows 原生桌面软件”的收录 / 合作入口，不要把现有 EXE 当作安卓 APK 提交。应用宝电脑版并不意味着所有 EXE 都能按移动应用流程上架。当前公开页面未能核实一个对所有开发者开放的 PC 自助提交入口，不能保证提交或审核结果；以平台当前后台要求和官方答复为准。

建议准备以下渠道资料，再按目标平台实际要求补齐：

1. 软件名称、简介、图标、清晰截图、使用手册、版本更新说明、官网和反馈方式。
2. 稳定的 HTTPS 安装包链接、版本号、架构、SHA256、安装与卸载流程。
3. 作者 / 主体信息及软件权属材料；具体是否需要企业主体、软著等，以平台要求为准。
4. 与实际行为一致的隐私说明，列清更新检查、远程图片、日志和后续广告 / 支付网络访问。
5. Windows 代码签名、Mac Developer ID 签名与公证作为发行准备；这些与渠道收录、系统默认应用注册是不同事项。目前本地 Mac 包尚未 Apple 公证。

也可评估 Microsoft Store、Mac App Store、官网与 GitHub 下载。每个商店的安装包、签名、更新与支付要求需要分别适配，不能把现有包直接视作符合所有商店条件。
