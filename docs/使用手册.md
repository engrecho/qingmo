## 一、三分钟上手

### 第 1 步：装好应用

**Windows**：双击 `轻墨 Setup 1.1.0.exe` → 一路下一步 → 完成。
  
如果提示「未知发布者」，点「更多信息」→「仍要运行」。

**macOS**：解压 zip → 把 `轻墨.app` 拖进「应用程序」→ **右键点击它** → 选「打开」。

### 第 2 步：新建文档

按 `Ctrl+N`，或者点左上角第一个图标（一张纸加号）。

### 第 3 步：开始写

左边敲字，右边自动出效果。默认有一段欢迎文档，照着改就行。

### 第 4 步：保存

按 `Ctrl+S`，选个位置，起个名字，比如 `我的文章.md`。

**完事了。** 剩下的都是可选的锦上添花。

## 二、界面详解

```
┌────────────────────────────────────────────────────────────┐
│ 轻墨   周报.md          ✎ ⊞ ⌗ ...  ▦ ❝   ◫ ▨ ◐           │
├──────────────────────────┬─────────────────────────────────┤
│                          ┃                                 │
│  # 周报                   ┃   周报                          │
│                          ┃   ═════                         │
│  这周做了三件事：         ┃                                 │
│                          ┃   这周做了三件事：               │
│  - 重构了登录模块         ┃   • 重构了登录模块               │
│  - 修了 12 个 bug         ┃   • 修了 12 个 bug               │
│  - 写了周报              ┃   • 写了周报                    │
│                          ┃                                 │
│              ← 拖这条竖线 → ┃                                │
├──────────────────────────┴─────────────────────────────────┤
│ /Users/you/Documents/周报.md · 行 3, 列 2   ●未保存  128字  6行 │
└────────────────────────────────────────────────────────────┘
```

### 标题栏（左→右）

| 元素                    | 作用                                                 |
| --------------------- | -------------------------------------------------- |
| **轻墨**                | 应用标识                                               |
| **文档名**               | 当前打开的文件名                                           |
| 📄💾⬇️                | 新建 / 保存 / 导出 HTML                                  |
| H1 H2 H3              | 插入标题，再按一次变回正文                                      |
| **B** *S* `</>`       | 加粗 / 斜体 / 删除线 / 行内代码                               |
| ▦ ❝ ❮❯ • 1. ☑ — 🔗 🖼 | 表格 / 引用 / 代码块 / 有序列表 / 无序列表 / 任务列表 / 分隔线 / 链接 / 图片 |
| ✎              | **预览区直接编辑**开关（`Ctrl+Shift+P`）                    |
| ◫ ▨ ◐                 | 视图切换（编辑 / 分栏 / 预览）、深色模式                            |

> 悬停任意图标会显示快捷键提示。

### 预览区直接编辑

默认预览区是**只读**的 —— 只能看，改字得去左边。

按 `Ctrl+Shift+P`（或点标题栏那个铅笔图标）之后：

- 预览区变成**可以直接打字**的
- 鼠标移到某一段上，会有一圈很淡的描边，提示「这块能改」
- 在预览区改字 → 左边的 Markdown 源码**同步更新**
- 勾选任务列表的方框 → 源码里的 `[ ]` 变成 `[x]`
- 点链接不会跳走，会用浏览器新标签打开

**适合什么场景**：写完初稿后通读润色。不用来回盯着左边看 `#`、`**`、`- ` 这些符号，眼睛只在成稿上移动。

**几个要注意的**：

| 操作 | 结果 |
| --- | --- |
| 在段落里改字 | 正常，那一段的 Markdown 会被替换成新内容 |
| 用方向键 / 鼠标选中文本 | 正常，就是普通的文本选择 |
| 想插新段落 | 按 `Enter`。Markdown 用空行分段，程序会自动补上 |
| 想在块首删除、并回上一段 | 光标停在块最开头，按 `Backspace` |
| 粘贴 | 只取纯文本，不会把网页的样式带进来 |
| 粘贴 Markdown 源码 | 不会被当源码插入，会按字面显示 —— 需要插源码请去左边 |

**局限**（说清楚免得踩坑）：

- 粒度是**块**。你在预览区改一段文字，只有那一段的源码会被重写；段落里的 `**粗体**`、`[链接](...)` 这类行内标记会被正确保留，但不是逐字符还原。
- 在预览区里**不能**插标题、表格这类结构。要插结构请用工具栏按钮，或者去左边。
- 代码块里能正常打字，但结构（语言标识如 ```` ```js ````）不会变。

切换开关的状态会被记住，下次打开还是你上次的选择。

### 中间的竖线

按住上下拖不动，**左右**拖可以调整两侧宽度。
  
范围限制在 20% ~ 80%，防止某一边被挤没。

### 状态栏

| 显示                 | 含义       |
| ------------------ | -------- |
| `文件路径 · 行 12, 列 4` | 光标在哪     |
| `● 未保存`（橙色）        | 有改动还没保存  |
| `已保存`（绿色）          | 已存盘      |
| `1,284 字`          | 不含空格的字符数 |
| `96 行`             | 总行数      |

## 四、Markdown 语法速查

轻墨的预览区支持标准 Markdown + GitHub 扩展语法（GFM）。

| 想要的效果   | 怎么写                        |
| ------- | -------------------------- |
| 标题      | `# 一级` `## 二级` `### 三级`    |
| **粗体**  | `**文字**`                   |
| *斜体*    | `*文字*`                     |
| ~~删除线~~ | `~~文字~~`                   |
| 行内代码    | `` `代码` ``                 |
| 代码块     | 三个反引号包起来                   |
| 引用      | `> 引用内容`                   |
| 无序列表    | `- 项目`                     |
| 有序列表    | `1. 项目`                    |
| 任务列表    | `- [ ] 未完成` / `- [x] 已完成`  |
| 表格      | 用 `\|` 分列，第二行写 `\| --- \|` |
| 分隔线     | `---`                      |
| 链接      | `[文字](网址)`                 |
| 图片      | `![描述](图片地址)`              |
| 换行      | 行尾两个空格，或空一行的段落             |

### 表格怎么写

```markdown
| 列A | 列B |
| --- | --- |
| 内容1 | 内容2 |
```

渲染效果：

| 列A  | 列B  |
| --- | --- |
| 内容1 | 内容2 |

**注意**：第二行的 `---` 不能少，否则不认成表格。
  
但你不用手写——选中几行按 `Ctrl+T` 就行。

## 五、提效技巧

### 1. 写作用源码，润色用预览

这是轻墨最值得用的组合：

| 阶段 | 用哪个 | 为什么 |
| --- | --- | --- |
| 搭结构 | `Ctrl+1` 仅源码 | 插标题、表格、代码块靠工具栏按钮最准 |
| 写内容 | `Ctrl+2` 分栏 | 边写边看排版效果 |
| 通读润色 | `Ctrl+3` + `Ctrl+Shift+P` | 直接在成稿上改字，眼睛不用看符号 |

预览区直编的详细用法见前面「界面详解」那节。

### 2. 选中多行秒变表格

写表格对齐符号很累。选中内容行：

```
产品名
价格
库存
```

按 `Ctrl+T`，得到：

```markdown
| 产品名 | 价格 | 库存 |
| --- | --- | --- |
|  |  |  |
```

光标停在空格里填内容即可。

### 3. 标题可以升降级

光标在标题行，按 `Ctrl+Alt+1` 变一级标题，
  
再按 `Ctrl+Alt+3` 变三级，**再按一次 `Ctrl+Alt+3`** 就变回正文。

### 4. 括号自动补全

输入 `(`、`*`、`_`、`` ` ``、`[`，轻墨会自动补上后半截，
  
光标停在中间，直接继续打就行。按 `End` 跳到末尾。

### 5. Tab 缩进

在列表里按 `Tab` 缩进一级变子项，`Shift+Tab` 提回来。

```
- 第一层
    - 第二层
```

### 6. 草稿不会丢

边打字边自动存本地。就算你直接杀进程强制关机，下次打开
  
文档还在（状态栏会显示「未保存」的橙色圆点）。

正式 `Ctrl+S` 保存成 `.md` 文件后，暂存清空。

## 六、常见问题

### Q：Windows 提示「未知发布者」怎么办？

轻墨没有购买微软的代码签名证书（一年几百美元，个人项目通常不做）。
  
点「更多信息」→「仍要运行」就行。

### Q：macOS 双击打不开，提示「已损坏」

因为没有 Apple 签名和公证，系统默认拦截。**右键点击 → 打开** 就好。

还不行的话，终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/QingMo.app
```

### Q：能打开 .md 文件吗？

能。用「文件 → 打开」选 `.md` 文件，或直接把文件拖进窗口。

### Q：导出 HTML 是干什么的？

生成一个独立的 `.html` 网页文件，双击就能在浏览器打开，
  
自带排版样式和深色模式适配。适合发给别人或放到网站。

### Q：支持哪些扩展名？

默认识别 `.md` `.markdown` `.mdown` `.mkd`。

### Q：文件会传到网上吗？

不会。轻墨完全离线运行，没有服务器、没有账号、不收集任何数据。

### Q：能装到手机吗？

不行，轻墨是桌面应用（Windows / macOS）。

### Q：怎么换字体？

编辑器字体在 `style.css` 的 `--mono` 变量，
  
预览字体在 `--font` 变量，改完重新打包即可。

## 七、文件放哪里

轻墨本身不管理文件，你保存到哪它就打开哪个。

Windows 常见的：

- 文档：`C:\Users\你的用户名\Documents\`
- 桌面：`C:\Users\你的用户名\Desktop\`

macOS 常见的：

- 文稿：`~/Documents`（访达 → 前往 → 个人，或按 `⌘+Shift+H` 看主目录）

### 建议的整理方式

```
Documents/
├── 工作/
│   ├── 周报/
│   │   ├── 2026-W42.md
│   │   └── 2026-W43.md
│   └── 项目/
│       └── 需求文档.md
└── 笔记/
    └── 读书笔记.md
```

轻墨的「最近打开」菜单会记录最近用过的 10 个文件，
  
找起来比翻文件夹快。

## 导出 PDF（1.6.8 起）

点击顶部 PDF 导出图标，或选择“文件 → 导出 PDF…”，选择保存路径。无需先保存 Markdown，会导出当前编辑内容。A4 自动分页、浅色背景，不包含工具栏、侧栏和大纲面板。标题、列表、表格及可读取图片保留；字体依赖本机字体，HTTPS 远程图片需联网，本地图片请确认路径有效。取消保存不产生文件；失败时会提示原因。

“大纲”入口现为工具栏中的目录图标，悬停提示“显示或隐藏文档大纲”；点击仍可切换，原有开关状态继续保留。

## 文件状态、重命名与最近关闭（1.6.9 起）

侧栏文件名右侧的圆点表示有未保存修改。保存或撤销回已保存内容后消失。打开、切换、纯阅读和改变主题不会产生文档修改。新建的空白文档关闭不提示；已经存在的文件若被清空但未保存，仍需确认，以免误删原文。

双击侧栏文件名或顶部标题，或按 F2，输入新文件名。未输入扩展名时沿用原扩展名（新文档为 .md）。有文件路径的文档在原目录重命名，保留尚未保存的正文；如果已有同名文件则拒绝覆盖。新文档只改变待保存名称，首次保存时仍需选择位置。

侧栏“最近关闭”显示最多 20 个文件与完整路径。点击可重新打开，或按 Ctrl/Cmd+Shift+T 打开上一个。记录保存在本机，重启仍保留；打开时读取磁盘内容，明确放弃的编辑不会恢复。文件已被删除或移动时会提示失败，不改变当前文档。

## 关闭窗口、后台保留与退出（1.6.9 起）

设置 → 文件 → “关闭窗口后留在后台”默认关闭。开启后，关闭窗口只隐藏，不询问保存，当前标签和修改留在内存与会话暂存中。Mac 点击 Dock 图标可返回；Windows 再次启动轻墨会唤起原窗口，不另开实例。

Mac 使用 Cmd+Q 或轻墨菜单的退出命令真正退出；Windows 使用 Ctrl+Q 或设置中的“退出应用”。退出执行关闭全部，提示列出具体未保存文件名与路径，可保存全部、放弃（需二次确认）或返回编辑器。取消保存、写入失败或取消退出时不丢弃文档。成功退出后不自动重开全部标签，文件可从“最近关闭”选回。

Cmd/Ctrl+W 关闭当前标签；Mac Cmd+Shift+W 关闭窗口，是否留后台遵循设置。
