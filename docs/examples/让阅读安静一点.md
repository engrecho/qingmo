# 让阅读安静一点

收起源码，换成深色。让一整篇文章，在眼前慢慢展开。

> 好的工具，是想写的时候，随时都能开始。

## 先把注意力留给内容

不必在不同窗口之间切换。写草稿时看源码，通读时看预览；需要润色的地方，直接修改。

**从一句话到一篇文章，始终留在同一个写作空间。**

## 让每次整理，都有迹可循

- 用标题建立层次，而不是靠反复滚动寻找段落。
- 用清单标记进展，让下一步清晰可见。
- 用本地 Markdown 保存内容，让文件始终在自己手里。

## 给今天的写作，一个小小的收尾

- [x] 记下一个新想法
- [x] 完成一段认真写的文字
- [ ] 保存文档，明天继续
