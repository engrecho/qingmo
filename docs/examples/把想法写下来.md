# 把想法写下来

一段文字，从灵感到成稿，只需要一个安静的地方。

> 少一点界面干扰，多一点思考的空间。

## 从一句话开始

不必先想好所有细节。记下关键词，让思路慢慢长出来。

- **记录灵感**：留住突然想到的那句话
- **整理结构**：用标题串起文章的脉络
- **打磨表达**：在预览里读一遍、改一遍

## 写作，也可以很有条理

| 阶段 | 现在要做的事 |
| --- | --- |
| 草稿 | 先写下来，不急着修改 |
| 整理 | 调整标题与段落顺序 |
| 定稿 | 通读预览，导出分享 |

## 留一点时间给好想法

- [x] 写下今天最想表达的主题
- [x] 整理出三个核心观点
- [ ] 把最后一段留给明天的自己

写得慢一点，也没关系。
